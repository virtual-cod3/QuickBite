# QuickBite – Online Food Ordering Website

**Your Craving, Our Kitchen.**

QuickBite is a modern, responsive online food ordering website designed to provide a smooth and convenient food ordering experience. Users can explore food categories, browse products, add items to their cart, customize quantities, and place orders through a simple checkout process.

## Live Website

🌐 **[Visit QuickBite](https://virtual-cod3.github.io/QuickBite/)**

## Features

- **Modern Homepage** – Clean and attractive landing page.
- **Food Categories** – Browse Burgers, Pizza, Drinks, and Desserts.
- **Product Listings** – Explore food items with images, descriptions, and prices.
- **Shopping Cart** – Add, remove, and update product quantities.
- **Order Summary** – Automatically calculates the order total.
- **Delivery & Takeaway** – Choose between home delivery and takeaway.
- **Payment Options** – Cash and simulated card payment options.
- **Order Confirmation** – Displays confirmation after successful checkout.
- **Responsive Design** – Optimized for desktop and mobile devices.

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/virtual-cod3/QuickBite.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start exploring the website and placing demo orders.

## Payment Information

QuickBite currently provides simulated payment options for demonstration purposes. It does not process real card payments or connect to a payment gateway.
